# Home

This vault is the second brain of my **Smart OS**.

An orchestrator agent routes the work while Claude Code, Codex or Cursor do it. The rules for the AI live in [[AGENTS]].

## How it works

Sources go into `raw/`. The AI compiles them into `wiki/`. Work gets produced into `outputs/`: agents write to `outputs/agent/`, I keep my polished, final versions in `outputs/human/`. Good answers get filed back into the wiki. Everything is grouped by operating system.
